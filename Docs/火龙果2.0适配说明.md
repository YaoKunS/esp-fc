## 一、板子与三个"兄弟"固件的关系

火龙果 2.0 与耀坤 S3 无人机是**同一系列、同一套 PCB 板框外形**（2026-11-27 用户确认），
自研飞控、Flix 耀坤整理版、ESP-FC V1.1 三个固件都已适配。因此：

- **IMU 安装方向完全一致** ⇒ ESP-FC 的朝向自动分档（按总线判，与板型无关）原样生效，
  本适配**不写任何方向代码**；
- **混控/电机布局沿用 S3 实测结论**，只换引脚号；
- 180° 反插坑同样存在（见 §四）。

ESP-FC 上游本来就支持经典 ESP32，且其 VSPI（18/19/23/CS5）与 I2C（21/22）
恰好与火龙果一致 —— 所以本适配只改了**一个 Target 头文件 + 一个编译环境**，
上游算法与耀坤 S3 适配层零改动。

## 二、与 S3 版（耀坤 PCB）的差异总表

| 项 | 耀坤 S3（V1.1） | 火龙果 2.0（本版） | 说明 |
|---|---|---|---|
| 芯片 | ESP32-S3 R8N8（8MB+PSRAM） | **ESP32 经典片 WROOM（4MB，无 PSRAM）** | env 不同，**不可互刷** |

| IMU SPI CS | 42（V2）/ 17（V1） | **5** | 经典片无 GPIO42！ |
| IMU I2C | SDA9 / SCL8 | **SDA21 / SCL22** | |
| MSP 串口 | UART0 43/44 + 原生 USB CDC | **仅 UART0（GPIO1/3，板载 CH340）** | 经典片无原生 USB |
| SBUS | GPIO1 | **GPIO4** | |
| 蜂鸣器 | 39 | **25** | 都是有源，高电平响 |
| LED | 三色（41/7/14，只驱动蓝灯） | **单色灯 GPIO2** | 拉电流接法 |
| 电池 ADC | GPIO2（1:2 分压） | **GPIO35（100K+100K 1:2 分压）** | GPIO35=ADC1，仅输入 |

| Flash 分区 | default_8MB.csv | **partitions_4M_nota.csv** | app 上限 1.25MB，本版用 1.01MB |

## 三、引脚总表（定稿）

引脚基线 = flix `board.h` 的 `BOARD_HLG_V2` 与自研 `config.h` 的 `PCB_HLG_V2`（两者逐脚一致）。

| GPIO | 功能 | ESP-FC 宏 | strapping / 注意 |
|---|---|---|---|
| 27 | 电机 右后 RR | `ESPFC_OUTPUT_0` | 混控序号 1 |
| 33 | 电机 右前 FR | `ESPFC_OUTPUT_1` | 混控序号 2 |
| 26 | 电机 左后 RL | `ESPFC_OUTPUT_2` | 混控序号 3 |
| 32 | 电机 左前 FL | `ESPFC_OUTPUT_3` | 混控序号 4 |
| 18 / 23 / 19 | SPI SCLK / MOSI(SDI) / MISO(SDO) | `ESPFC_SPI_0_*` | VSPI 默认，勿动 |
| 5 | MPU6500 CS | `ESPFC_SPI_CS_GYRO` | 内部上拉；strapping 高=正常 |
| 22 / 21 | I2C SCL / SDA | `ESPFC_I2C_0_*`（SOFT） | 排母：6050 / MS5611 / 磁罗盘 |
| 25 | 蜂鸣器 | `ESPFC_BUZZER_PIN` | ADC2 组，仅输出无碍 |
| 35 | 电池 ADC | `ESPFC_ADC_VBAT_PIN` | **仅输入**；分压 `2.0/4096` |
| 2 | 板载 LED | `ESPFC_LED_PIN` | strapping 低=下载；拉电流接法 |
| 4 | SBUS 输入 | `ESPFC_INPUT_PIN` | |
| 1 / 3 | UART0 TX/RX（MSP） | `ESPFC_SERIAL_0` | 板载 CH340，115200 |
| 13 / 14 / 12 / 15 | 光流 PMW3901（**未启用**） | — | 本版无光流驱动 |
| 16 / 17 | I2C1 预留（VL53L1X） | — | 未启用；WROVER 模组被 PSRAM 占 |

**串口裁剪（🔴 重要）**：上游经典 ESP32 模板把 `SERIAL_1` 配在 TX33/RX32 —— 正好是
右前/左前电机脚，`SERIAL_2` 配在 17/16 —— 是 I2C1 预留。本 Target **全部显式 -1**，
否则串口初始化会抢走电机。也**不能定义** `ESPFC_SERIAL_USB`（经典片无原生 USB），
调试口固定 `SERIAL_UART_0`。

## 四、🔴 经典 ESP32 的铁律（与 S3 版不同，逐条都咬过人）

1. **只有 GPIO0~39**：S3 版的 40 以上编号（如 V2 板 CS=42）在经典片上是
   越界写寄存器（未定义行为）。本 Target 所有引脚 ≤39，不用的写 -1。
2. **GPIO6~11 是 Flash 专用**，30 针 DevKit 上不能当 IO 用。
3. **ADC2 与 Wi-Fi 互斥**：本固件 Wi-Fi 常开（ESP-NOW 无线 MSP），
   电池 ADC 必须落在 ADC1（32/33/34/35/36/39）。本板用 GPIO35=ADC1_CH7 ✅；
   **将来改板也绝不能把 ADC 挪到 ADC2 组**（2/4/12~15/25~27），否则读数恒 0
   → 误判低电 → 蜂鸣器无限急鸣。
4. **GPIO12 = MTDI strapping**：悬空有内部弱下拉（复位读低 → 3.3V Flash 正常）。
   将来接光流模块时，模块 MIS 的上拉会让 Flash 判成 1.8V → 反复重启；
   解法 = 烧 eFuse 固定 3.3V（官方推荐、不可逆）或加 10k 下拉。
5. **GPIO2 既是 LED 又是 strapping**：拉电流接法（GPIO2→电阻→LED→GND）
   在复位期呈高阻，不影响 boot；别把它改成灌电流或外加高电平。

## 五、IMU 朝向自动分档（沿用，零新逻辑）

`gyro_align=DEFAULT` 时按总线自动选（与 S3 版同一套代码、同一组档位）：

- **I2C 排母 MPU6050 → CW270**
- **SPI 座 MPU6500 → CW90**

⚠️ 排母/SPI 座允许 **180° 反插**，插装方向一变正确档位就变
（症状 = pitch/roll 双反相）。**建议在模块和排母上做对位标记**。
现场试档：CLI `set gyro_align CW270`（6050）或 CW90（6500）实时生效——
但 🔴 **`exit` 退出 CLI 会触发重启，`set` 未 `save` 的值会丢失**，
所以试档期间**不要退出 CLI**，直接在 CLI 里连着 BF 看 3D；确认对了再 `save`。
换 IMU 类型后用 `set gyro_align DEFAULT` → `save` 恢复自动分档。

## 六、验证流程（三级，照 S3 版老规矩）

| 级 | 项目 | 判据 |
|---|---|---|
| 1 编译 | `pio run -e esp32_hlg20` | 通过；app ≤ 1.25MB（本版 1.01MB） |
| 2 烧录 | COM 口（板载 CH340），SHA 校验 | 串口有启动横幅、BF 能识别 |
| 3 台架 | **清 NVS**（换板型刷机必做） | CLI `defaults` → `save` → `reboot` |
| 3 台架 | 3D 姿态（6050 与 6500 各一次） | 抬头=抬头、右倾=右倾 |
| 3 台架 | 电机测试（**拆桨**） | 推油门对角两颗同转、偏航正确一对加速 |
| 3 台架 | 电压 | 万用表对比，误差 < 0.2V |
| 3 台架 | 蜂鸣器 / LED | 上电提示音、状态灯正常 |
| 3 台架 | 解锁门控 | 未解锁推油门电机不转 |

## 七、故障速查

| 现象 | 根因 | 处理 |
|---|---|---|
| 地面站搜不到板子 | 烧错 env（必须 `esp32_hlg20`） | 换 env 重烧 |
| 上电无串口输出 | CH340 驱动 / 接线 | 装驱动、查 GPIO1/3 |
| 烧录失败 / 反复重启 | GPIO12 被拉高（光流模块） | 拔模块；长期用 eFuse 或 10k 下拉 |
| 四电机全不转 | 漏 `-DESPFC_DEV_PRESET_BRUSHED` | 加宏重编 |
| 蜂鸣器常鸣 | 烧成上游 `esp32` 固件（其电机表含 25=蜂鸣器） | 改烧 `esp32_hlg20` |
| 推油门不对角转 | 混控序号 ≠ 丝印（差一个交叉） | 按 §三 OUTPUT 表核对 |
| pitch/roll 双反相 | 模块 180° 反插 | 对位标记；`set gyro_align` 试档 |
| 换 IMU 后姿态错 | NVS 固化旧 `gyro_align` | `set gyro_align DEFAULT` → `save` |
| 电压为 0 / 差一倍 | ADC 被挪到 ADC2 组 / 系数错 | 保持 GPIO35，`2.0f/4096` |
| 气压计读不到 | 接线松 / SDA-SCL 对调拉死总线 | 查 VCC/GND/SDA(21)/SCL(22)，重插 |
| app 烧不进去（超限） | 4MB 分区 app 上限 1.25MB | 盯固件体积，精简功能 |
